A python tool i built to practice phishing-email-investigation. It takes raw .eml it checks email security records such as SPF/DKIM/DMARC results. It also verifies sender domain match and scan for suspicious link or IP addresses.

On analysis the results are High and score risk is 7.

I created this analyzer to get hands on with SPF/DKIM/DMARC and understand how alignment check work in real life phishing.
